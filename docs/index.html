Construa Interfaces Web Incríveis para o DTunnel VPN

O DTunnel SDK é a biblioteca padrão em TypeScript/JavaScript para criar layouts HTML, React e WebViews completas com controle total de conexão VPN, categorias de servidores, importação offline, anúncios premiados e integração com hardware Android.

Instalação

Instale o pacote via seu gerenciador de pacotes favorito ou use a CDN:

npm install dtunnel-sdk
pnpm add dtunnel-sdk
yarn add dtunnel-sdk
<!-- Core do SDK -->
<script src="https://cdn.jsdelivr.net/npm/dtunnel-sdk@latest/sdk/dtunnel-sdk.js"></script>
<!-- Simulador opcional para testes no PC -->
<script src="https://cdn.jsdelivr.net/npm/dtunnel-sdk@latest/sdk/dtunnel-sdk.simulator.js"></script>

Gerador de Projetos Pronto (init)

A forma mais rápida e recomendada de iniciar um novo layout é usar o comando oficial init. Ele cria a estrutura pronta com scripts de build empacotados para o Android:

Terminal 
# Modo interativo (selecione o template no terminal)
npx dtunnel-sdk init meu-layout

# Ou crie direto com o template desejado:
npx dtunnel-sdk init meu-layout --template react-typescript
npx dtunnel-sdk init meu-layout --template typescript
npx dtunnel-sdk init meu-layout --template cdn
💡
Script build:android Automático:

Todos os templates gerados pela CLI já incluem o comando npm run build:android, que compila todo o JavaScript e CSS em um arquivo único dist/build.html compatível diretamente com o WebView do DTunnel VPN.

Guia Rápido de Uso

Veja como instanciar o SDK, escutar eventos da VPN e disparar ações:

src/index.ts 
import DTunnelSDK from 'dtunnel-sdk';

// 1. Inicializa o SDK
const sdk = new DTunnelSDK({
  strict: false,                 // Não lança exceção caso um método não exista
  autoRegisterNativeEvents: true // Registra automaticamente os callbacks globais
});

// 2. Escuta mudanças de estado da VPN
sdk.on('vpnState', (event) => {
  console.log('Estado da VPN:', event.payload); // 'CONNECTED' | 'DISCONNECTED' | 'CONNECTING'
});

// 3. Ações
document.getElementById('btnConnect')?.addEventListener('click', () => {
  sdk.main.startVpn();
});

document.getElementById('btnDisconnect')?.addEventListener('click', () => {
  sdk.main.stopVpn();
});

DTunnelSDK (Classe Principal)

A classe DTunnelSDK é o ponto de entrada central. Ela gerencia o ciclo de vida da bridge, eventos nativos e fornece instâncias de todos os submódulos.

new DTunnelSDK(options?: DTunnelSDKOptions)
CONSTRUCTOR

Cria uma nova instância do SDK.

OPÇÃO TIPO PADRÃO DESCRIÇÃO
strict boolean false Se true, lança DTunnelBridgeError quando um objeto não for encontrado.
autoRegisterNativeEvents boolean true Se true, registra automaticamente todos os callbacks nativos no window global.
window DTunnelBridgeHost window Objeto host onde os objetos Dt... estão localizados.
logger Pick<Console, 'error'> console Instância customizada de logger.
sdk.on(eventName, listener): () => void
EVENT

Inscreve um ouvinte para um evento semântico, nativo ou erro. Retorna função para cancelar a inscrição.

Retorno: () => void — Função de cancelamento da inscrição.
sdk.getBridgeAvailability(): Record<DTunnelBridgeObjectName, boolean>
GET

Retorna um mapa booleano com a disponibilidade de cada um dos 53 objetos nativos de bridge no ambiente atual.

sdk.createDebugSnapshot(): DTunnelDebugSnapshot
GET

Gera uma fotografia completa de telemetria e diagnóstico contendo opções ativas, disponibilidade de pontes e lista de callbacks registrados.

Módulo sdk.main (VPN, Conexão e Anúncios)

Controla o ciclo de vida da conexão VPN, diálogos do sistema, checagem de usuário e anúncios premiados.

sdk.main.startVpn(): void
ACTION

Inicia a conexão VPN com a configuração e credenciais atualmente selecionadas.

Bridge: window.DtExecuteVpnStart.execute()
sdk.main.stopVpn(): void
ACTION

Interrompe a conexão VPN ativa.

Bridge: window.DtExecuteVpnStop.execute()
sdk.main.getVpnState(): DTunnelVPNState | null
GET

Retorna o estado atual da VPN: 'CONNECTED' | 'DISCONNECTED' | 'CONNECTING' | 'STOPPING' | 'NO_NETWORK' | 'AUTH' | 'AUTH_FAILED'.

Retorno: DTunnelVPNState | null
sdk.main.isVpnRunning(): boolean
GET

Retorna true se o serviço de VPN estiver ativo e em execução no Android.

Bridge: window.DtIsVpnRunning.execute()
sdk.main.showAdsRewardedDialog(): void
ACTION

Abre o diálogo nativo para exibição de vídeo premiado (adicionando tempo de conexão ao usuário).

Bridge: window.DtShowDialogAdsRewarded.execute()
sdk.main.getRemainingConnectionTime(): number | null
GET

Retorna o tempo restante de conexão em segundos (ex: 7200 para 2 horas).

sdk.main.getRemainingConnectionTimerText(): string | null
GET

Retorna o tempo restante de conexão formatado em texto (ex: "02:45:10").

sdk.main.getLastVpnError(): string | null
GET

Retorna a mensagem descritiva do último erro ocorrido na conexão VPN (se houver).

sdk.main.startCheckUser(): void
ACTION

Dispara a verificação das credenciais e validade do usuário via API SSH/Painel. O resultado chega pelo evento checkUserResult.

Módulo sdk.config (Categorias, Servidores e Importação)

Gerencia configurações de servidores, categorias, credenciais e importação segura offline.

sdk.config.getCategories(): DTunnelCategorySummary[] | null
GET

Retorna a lista resumida de categorias disponíveis com contagem de configurações associadas ({ id, name, color, sorter, count }).

[ { "id": 10, "name": "Brasil", "color": "#532e7d", "sorter": 1, "count": 12 }, { "id": 20, "name": "Estados Unidos", "color": "#1a4480", "sorter": 2, "count": 6 } ]
sdk.config.getConfigsByCategory(categoryId: number): DTunnelConfigListItem[] | null
GET

Retorna todas as configurações pertencentes à categoria informada.

PARÂMETROTIPODESCRIÇÃO
categoryIdnumberID numérico da categoria desejada.
sdk.config.getSelectedConfig(): DTunnelDefaultConfig | null
GET

Retorna o objeto completo da configuração que está selecionada para conexão.

sdk.config.setConfig(id: number): void
SET

Define a configuração ativa pelo seu ID numérico.

sdk.config.getImportPublicKey(): string | null
GET

Retorna a chave pública criptográfica do aplicativo utilizada para criptografar envelopes de importação offline.

sdk.config.getUser(): DTunnelUserCredentials | null
GET

Retorna as credenciais salvas do usuário ({ username, password, uuid }).

Módulo sdk.android (Hardware & Sistema Android)

Acesso a recursos nativos do sistema operacional Android.

sdk.android.copyToClipboard(text: string): void
ACTION

Copia um texto diretamente para a área de transferência do Android, contornando bloqueios de permissão do navegador.

sdk.android.showToast(message: string): void
ACTION

Exibe um Toast nativo flutuante na tela do dispositivo.

sdk.android.vibrate(durationMillis?: number): void
ACTION

Aciona o motor de vibração tátil do dispositivo (duração padrão: 50ms).

sdk.android.isDarkMode(): boolean
GET

Retorna true se o tema escuro estiver ativo no sistema operacional.

sdk.android.getAppColors(): DTunnelAppColors | null
GET

Retorna a paleta de cores hexadecimais configuradas dinamicamente no app Android ({ backgroundColor, cardColor, textColor, buttonColor... }).

sdk.android.getDiagnosticReport(): string | null
GET

Gera um relatório completo de diagnóstico com modelo do aparelho, versão do Android, IP, logs recentes e status de rede.

Módulo sdk.app (Configurações & Telas do Sistema)

Acesso a telas nativas do sistema operacional e configurações chave-valor do aplicativo.

sdk.app.getAppConfig<T>(name: string): { value: T } | null
GET

Obtém uma configuração chave-valor definida remotamente no painel (ex: "support_url", "banner_ad_id").

sdk.app.startApnActivity(): void
ACTION

Abre a tela nativa de configurações de APN (Ponto de Acesso Móvel) do Android.

Módulo sdk.text (Internacionalização Dinâmica)

Permite traduzir labels e textos do layout respeitando as strings dinâmicas fornecidas pelo app.

sdk.text.translate(label: string | null): string | null
GET

Traduz uma chave de string registrada no serviço de tradução do aplicativo.

Eventos & Callbacks Nativos

O SDK padroniza todos os eventos nativos disparados pelo app através do método sdk.on(eventName, handler):

EVENTO SEMÂNTICO CALLBACK NATIVO DESCRIÇÃO DO PAYLOAD
vpnState DtVpnStateEvent Status atual da VPN (CONNECTED, CONNECTING, etc.)
vpnStartedSuccess DtVpnStartedSuccessEvent Disparado quando o handshake da VPN foi concluído com sucesso.
vpnStoppedSuccess DtVpnStoppedSuccessEvent Disparado quando o túnel foi completamente encerrado.
newDefaultConfig DtNewDefaultConfigEvent Disparado quando o usuário troca a configuração selecionada.
checkUserResult DtCheckUserResultEvent Objeto JSON com conexões ativas, limite e data de validade.
checkUserError DtCheckUserErrorEvent Mensagem de erro na checagem de usuário.
messageError DtMessageErrorEvent Objeto JSON com título e descrição de erro do app.
showSuccessToast DtSuccessToastEvent Texto da mensagem de sucesso a ser exibida.
showErrorToast DtErrorToastEvent Texto da mensagem de erro a ser exibida.
notification DtNotificationEvent Notificação push recebida em primeiro plano.
localIp DtLocalIpEvent Endereço IP local atual do dispositivo.
networkName DtNetworkNameEvent Nome da operadora móvel ou SSID do Wi-Fi conectado.
pingResult DtPingResultEvent Latência de ping em milissegundos.

Integração com React

O pacote inclui bindings oficiais para React 18+ via dtunnel-sdk/react:

App.tsx 
import React, { useState } from 'react';
import { DTunnelSDKProvider, useDTunnelSDK, useDTunnelEvent } from 'dtunnel-sdk/react';

function VpnDashboard() {
  const sdk = useDTunnelSDK();
  const [vpnState, setVpnState] = useState(sdk.main.getVpnState());

  // Escuta reativamente eventos da VPN
  useDTunnelEvent('vpnState', (event) => {
    setVpnState(event.payload);
  });

  return (
    <div className="card">
      <h2>Status: {vpnState ?? 'Desconectado'}</h2>
      <button onClick={() => sdk.main.startVpn()}>Conectar</button>
      <button onClick={() => sdk.main.stopVpn()}>Desconectar</button>
    </div>
  );
}

export default function App() {
  return (
    <DTunnelSDKProvider options={{ strict: false, autoRegisterNativeEvents: true }}>
      <VpnDashboard />
    </DTunnelSDKProvider>
  );
}

Simulador para Desenvolvimento Local

Desenvolva seu layout no seu computador sem precisar do celular ou do Android Studio instalado:

main.ts 
import DTunnelSDK from 'dtunnel-sdk';
import { installDTunnelSDKSimulator } from 'dtunnel-sdk/simulator';

// Instala os objetos simulados no window apenas se não estiver no WebView real
const simulator = installDTunnelSDKSimulator({
  autoEvents: true // Simula transições automáticas (CONNECTING -> CONNECTED)
});

// Você pode customizar os dados de teste:
simulator.setState({
  username: 'usuario_teste',
  remainingConnectionTimerText: '04:20:00'
});

const sdk = new DTunnelSDK();
console.log('Configs mockadas:', sdk.config.getConfigs());

Bridge Direta (Sem SDK)

Para desenvolvedores criando arquivos HTML puros legados, os 53 adaptadores nativos ficam disponíveis diretamente no escopo global window.Dt...:

index.html 
// Chamadas síncronas diretas:
window.DtExecuteVpnStart.execute();
const vpnState = window.DtGetVpnState.execute();
const categoriesJson = window.DtGetCategories.execute();

// Ouvir eventos nativos globais:
window.DtVpnStateEvent = function(state) {
  console.log('VPN State:', state);
};
